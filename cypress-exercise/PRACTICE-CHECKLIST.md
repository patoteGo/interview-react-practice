# Cypress Practice Checklist

## Setup
- [ ] Run `npm install`
- [ ] Run `npm run server`
- [ ] Run `npm run dev`

## App flow
- [ ] fetch todos
- [ ] render loading state
- [ ] render success state
- [ ] create todo
- [ ] toggle todo

## Cypress flow
- [ ] add `data-testid` selectors
- [ ] write happy-path test
- [ ] write empty or error test
- [ ] keep tests independent

## Confidence checks
- [ ] I can explain why a selector is stable
- [ ] I can explain why an assertion is user-visible
- [ ] I can type one Cypress happy-path spec from memory
