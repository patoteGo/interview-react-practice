# interview-react-practice

React live-coding practice exercises.

## New interview drills

- `react-bug-checkout-form` — fix a row identity/state bug in a checkout cart.
- `react-bug-tabs-profile` — fix an async race condition in tabbed profile loading.
- `react-optimize-product-grid` — speed up a sluggish product grid without changing behavior.

## Run any project

```bash
cd <project-folder>
npm install
npm run dev
```

There are also older exercises in the repo if you want more practice.
