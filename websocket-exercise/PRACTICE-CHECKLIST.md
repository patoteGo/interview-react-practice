# WebSocket Practice Checklist

## Setup
- [ ] install dependencies
- [ ] run socket server
- [ ] run frontend

## Connection
- [ ] connect to socket
- [ ] show connection status
- [ ] handle incoming messages

## Messaging
- [ ] send one JSON message
- [ ] render broadcast result
- [ ] handle malformed or unexpected data

## Resilience
- [ ] handle close
- [ ] try reconnect logic

## Confidence checks
- [ ] I can explain open/message/close
- [ ] I can explain my message shape
- [ ] I know what boundary to validate
